## Быстрая установка

### 1. Клонирование и установка зависимостей
```bash
# Создаем виртуальное окружение (рекомендуется)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows

# Устанавливаем зависимости
pip install -r requirements.txt
```

Примечание: TgCrypto ускоряет работу с Telegram API за счет оптимизированного шифрования.

### 2. Получение API данных Telegram
1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите под своим аккаунтом
3. Создайте новое приложение в разделе "API development tools"
4. Скопируйте `api_id` и `api_hash`

### 3. Создание Telegram-бота для управления
1. Напишите [@BotFather](https://t.me/botfather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Получите токен бота
4. Скопируйте токен для использования в конфигурации

## Создание Telegram сессий

Сессии создаются автоматически при первом запуске компонентов. **Важно:** добавляйте сессии по одной!

### Создание сессий сканеров:
```bash
# Активируем виртуальное окружение (если используете)
source venv/bin/activate

# Запускаем только сканеры для авторизации
python main.py scanner
```

Процесс авторизации:
1. Система найдет неавторизованные сессии из `SCANNER_SESSIONS`
2. Для каждой сессии попросит:
   - Номер телефона (в международном формате: +7XXXXXXXXXX)
   - Код подтверждения из SMS/Telegram
   - Пароль двухфакторной аутентификации (если включен)
3. Сессии сохранятся в папке `data/` как файлы `.session`

### Создание сессий покупателей:
```bash
# Запускаем только покупателей для авторизации
python main.py buyer
```

Процесс аналогичен сканерам.

### Важные моменты при создании сессий:
- Добавляйте по одной сессии - отредактируйте config.py, добавьте одну сессию, запустите, авторизуйтесь, затем добавляйте следующую
- Используйте разные аккаунты для сканеров и покупателей
- Рекомендуется: 2-3 сканера и столько покупателей, сколько пользователей
- Все аккаунты должны быть добавлены в рабочий канал TARGET_CHANNEL_ID

### Пример пошагового создания:
```bash
# Шаг 1: В config.py добавляем одну сессию
SCANNER_SESSIONS = ["scanner_1"]

# Шаг 2: Запускаем и авторизуемся
python main.py scanner

# Шаг 3: Добавляем следующую сессию
SCANNER_SESSIONS = ["scanner_1", "scanner_2"]

# Шаг 4: Запускаем снова
python main.py scanner

# И так далее...
```

## Система профилей и стратегий

### Концепция профилей
Каждый бот-покупатель поддерживает до 4 профилей закупки. Каждый профиль содержит 4 стратегии с уникальными приоритетами (1 — самый высокий, 4 — самый низкий).

### Структура профиля:
```
Профиль "default":
├── Стратегия 1 (Приоритет 1): 1000-10000 ⭐, лимит: 5000 ⭐
├── Стратегия 2 (Приоритет 2): 500-999 ⭐, лимит: 3000 ⭐  
├── Стратегия 3 (Приоритет 3): 100-499 ⭐, лимит: 2000 ⭐
└── Стратегия 4 (Приоритет 4): 1-99 ⭐, лимит: 1000 ⭐
```

### Параметры каждой стратегии:
- **Диапазон цен**: Минимальная и максимальная цена подарка (в звездочках ⭐)
- **Лимит трат**: Максимальная сумма для покупок по этой стратегии
- **Приоритет**: Порядок применения стратегий (1 = высший приоритет)
- **Потраченная сумма**: Текущие траты (сбрасываются ежедневно)

### Как работает выбор стратегии:
1. Сканер находит подарок и отправляет цену в рабочий канал
2. Покупатель получает цену и проверяет активный профиль
3. Система проверяет стратегии по приоритету (от 1 к 4):
   - Подходит ли цена в диапазон стратегии?
   - Хватает ли лимита для покупки?
   - Если да - покупка по этой стратегии
   - Если нет - проверяется следующая стратегия
4. Покупка совершается по первой подходящей стратегии
5. Статистика обновляется в реальном времени

### Создание и управление профилями:

#### Через Telegram-бот:
```
/start → Настройки → buyer_ваш_ник → Профили закупки
```

#### Операции с профилями:
- Создать профиль: До 4 профилей на покупателя
- Активировать: Переключение между профилями
- Редактировать стратегию: Настройка параметров
- Удалить профиль: Удаление ненужных (кроме default)

#### Редактирование стратегии:
Формат: `минимальная_цена максимальная_цена лимит_трат`
```
Пример: "100 500 2000"
├── Минимальная цена: 100 ⭐
├── Максимальная цена: 500 ⭐
└── Лимит трат: 2000 ⭐
```

## Система доступа и безопасности

### Права доступа:
- Обычные пользователи видят только свои боты (из BUYER_OWNERS)
- Администраторы из ADMIN_USERNAMES видят все боты
- Каждый пользователь может управлять только назначенными ему ботами

- Проверка лимитов - невозможно потратить больше установленного
- Валидация данных - проверка корректности настроек
- Автосброс трат - ежедневное обнуление счетчиков
- Защита профилей - нельзя удалить "default" и активный профиль

## Устранение неполадок

### Проблема: Бот не отвечает
```bash
# Проверьте токен и имя пользователя в config.py
# Перезапустите бота управления
python main.py config
```

### Проблема: Покупатель не работает
1. Проверьте статус через бота: Статистика
2. Убедитесь что покупатель включен
3. Проверьте лимиты трат в активном профиле
4. Посмотрите логи: `tail -f buyer.log`

### Проблема: Нет доступа к Telegram API
```python
# В app/config.py добавьте прокси:
PROXY_URL = "socks5://127.0.0.1:1080"  # SOCKS5 прокси
# или  
PROXY_URL = "http://proxy.example.com:8080"  # HTTP прокси
```

### Проблема: Сессия не создается
```bash
# Убедитесь что добавляете сессии по одной
# Проверьте правильность номера телефона (+7XXXXXXXXXX)
# Удалите частично созданные файлы .session и попробуйте снова
```

### Проблема: Конфигурация не применяется
1. Проверьте синтаксис JSON в `data/buyer_configs.json`
2. Убедитесь в правильной кодировке файла (UTF-8)
3. Перезапустите покупателя: `python main.py buyer`

### Альтернативное управление без бота:
Если Telegram-бот недоступен, можете редактировать `data/buyer_configs.json` напрямую:

```json
{
  "buyer_username": {
    "enabled": false,  // Отключить покупателя
    "active_profile": "conservative",  // Сменить профиль
    "profiles": {
      "conservative": {
        "strategy_1": {
          "min_price": 1,
          "max_price": 100, 
          "max_spend": 1000,
          "priority": 1,
          "current_spent": 0  // Сбросить траты
        }
      }
    }
  }
}
```

После изменения файла покупатель автоматически применит новые настройки.
