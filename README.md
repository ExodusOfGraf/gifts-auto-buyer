# 🎁 NFT Gift Auto-Buyer System

Автоматическая система для сканирования и покупки NFT-подарков в Telegram с **гибким управлением стратегиями покупки** через Telegram-бот.

## 🚀 Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
```

**⚡ Для максимальной производительности установите TgCrypto:**
```bash
pip install tgcrypto
```
> TgCrypto ускоряет работу с Telegram API в 5-10 раз за счет оптимизированного шифрования

### 2. Настройка Telegram-бота
Отредактируйте `app/config.py`:
```python
MANAGEMENT_BOT_TOKEN = "your_bot_token"
ADMIN_USERNAMES = ["your_telegram_username"]  # без символа @

# Если есть проблемы с доступом к Telegram API
PROXY_URL = "socks5://127.0.0.1:1080"  # Настройте прокси
```

### 3. Запуск
```bash
# Активируем виртуальное окружение
source venv/bin/activate

# Все компоненты
python main.py

# Отдельные компоненты
python main.py scanner    # Только сканеры
python main.py buyer      # Только покупатели
python main.py config     # Только бот управления
```

### 🎯 Система профилей закупки

Каждый бот-покупатель поддерживает **до 4 профилей** закупки, каждый профиль содержит **4 стратегии** с уникальными приоритетами (1 — самый высокий, 4 — самый низкий).

#### Структура профиля:
- **Стратегия 1** (Приоритет 1): Самый высокий приоритет
- **Стратегия 2** (Приоритет 2): Высокий приоритет  
- **Стратегия 3** (Приоритет 3): Средний приоритет
- **Стратегия 4** (Приоритет 4): Низкий приоритет

#### Параметры каждой стратегии:
- **Диапазон цен**: Минимальная и максимальная цена подарка (в звездочках ⭐)
- **Лимит трат**: Максимальная сумма для покупок по этой стратегии
- **Потраченная сумма**: Текущие траты (сбрасываются ежедневно)

#### Управление через Telegram-бот:
1. **Создание профилей**: До 4 профилей на каждого покупателя
2. **Активация профиля**: Только один профиль активен в каждый момент времени
3. **Редактирование стратегий**: Настройка параметров каждой стратегии
4. **Контроль доступа**: Каждый пользователь может управлять только своими ботами

#### Пример использования:
```
Профиль "Агрессивный":
├── Стратегия 1: 1000-10000 ⭐, лимит: 5000 ⭐ (премиум подарки)
├── Стратегия 2: 500-999 ⭐, лимит: 3000 ⭐ (средние подарки)
├── Стратегия 3: 100-499 ⭐, лимит: 2000 ⭐ (дешевые подарки)
└── Стратегия 4: 1-99 ⭐, лимит: 1000 ⭐ (очень дешевые)

Профиль "Консервативный":
├── Стратегия 1: 100-500 ⭐, лимит: 2000 ⭐
├── Стратегия 2: 50-99 ⭐, лимит: 1000 ⭐
├── Стратегия 3: 10-49 ⭐, лимит: 500 ⭐
└── Стратегия 4: 1-9 ⭐, лимит: 200 ⭐
```

```
Программист → Telegram Bot → buyer_configs.json → Buyer Process → Новые настройки
```

**Ключевая особенность:** Изменения применяются **БЕЗ ПЕРЕЗАПУСКА** системы!

3. **Покупатель** автоматически подхватывает изменения
4. **Новые правила** применяются к следующей покупке

## 🎯 Система стратегий и профилей

### 📋 Профили закупки
**Каждый бот может иметь до 4 профилей**, каждый профиль содержит 4 стратегии с приоритетами 1-4.

**Преимущества профилей:**
- 🔄 **Быстрое переключение** между стратегиями (утро/вечер, агрессивная/консервативная)
- 👤 **Персональный доступ** - каждый владелец видит только свои боты
- 🎯 **Одна активная** стратегия за раз
- 🚀 **Мгновенное применение** без перезапуска

### Структура конфигурации:
```json
{
  "buyer_andrei": {
    "profiles": {
      "default": {
        "strategy_1": {"min_price": 1000, "max_price": 10000, "max_spend": 5000, "priority": 1},
        "strategy_2": {"min_price": 500, "max_price": 999, "max_spend": 3000, "priority": 2},
        "strategy_3": {"min_price": 100, "max_price": 499, "max_spend": 2000, "priority": 3},
        "strategy_4": {"min_price": 1, "max_price": 99, "max_spend": 1000, "priority": 4}
      }
    },
    "active_profile": "default",
    "enabled": true,
    "owner_id": 12345
  }
}
```

### Параметры стратегии:
- **`min_price/max_price`** - диапазон цен (в звездах)
- **`max_spend`** - лимит трат на стратегию
- **`priority`** - приоритет (1 = самый высокий)
- **`current_spent`** - текущие траты (автоматически)

### Параметры профиля и бота:
- **`active_profile`** - активный профиль (default, evening, aggressive, etc.)
- **`owner_id`** - ID владельца бота (для прав доступа)
- **`enabled`** - включен/выключен
- **`auto_reset_daily`** - автосброс трат каждый день

### 🎮 Быстрый старт с профилями:
1. **Запустите бота:** `/start` в Telegram
2. **Выберите своего бота:** `⚙️ Настройки` → `buyer_ваше_имя`
3. **Настройте профиль:** `🎯 Профили закупки` → `default`
4. **Отредактируйте стратегию:** `1️⃣ Стратегия 1` → `"1 100 1000"`
5. **Готово!** Изменения применяются мгновенно

## 🎪 Демонстрация работы

### Пример сценария с профилями:
1. **Сканер** находит подарок за 150 ⭐
2. **Покупатель** получает цену и проверяет активный профиль "aggressive"
3. **Система проверяет стратегии профиля по приоритету:**
   - Стратегия 1 (1-10000 ⭐, приоритет 1): ✅ подходит по цене, лимит позволяет
   - Стратегии 2-4: пропускаются, так как стратегия 1 подошла
4. **Покупка** совершается по стратегии 1
5. **Статистика профиля** обновляется в реальном времени

### Смена профиля "на лету":
```
14:30 - Активен профиль "day_trading" (агрессивные покупки)
14:35 - Клиент через Telegram переключает на "conservative"  
14:36 - Система подхватывает изменения автоматически
14:37 - Следующая покупка идет по консервативным правилам
14:40 - Статистика показывает траты нового профиля
```

### Управление несколькими ботами:
```
15:00 - Клиент управляет 3 ботами: buyer_main, buyer_reserve, buyer_test
15:05 - В buyer_main активирует "weekend" профиль
15:10 - В buyer_reserve создает новый профиль "special"
15:15 - buyer_test оставляет на "default"
15:20 - Все боты работают независимо со своими профилями
```

## 🚨 Устранение неполадок

### Ошибки форматирования в Telegram-боте:
```
❌ can't parse entities: Can't find end of the entity
```
**Решение:** Обновлено форматирование сообщений с Markdown на HTML - проблема исправлена.

### Нет доступа к Telegram API:
```
❌ Cannot connect to host api.telegram.org
```
**Решения:**
1. **Проверьте интернет** - попробуйте открыть web.telegram.org
2. **Используйте VPN** - включите VPN и попробуйте снова
3. **Настройте прокси** в `app/config.py`:
   ```python
   PROXY_URL = "socks5://127.0.0.1:1080"
   ```
4. **Ручное управление** - редактируйте `data/buyer_configs.json` напрямую

### Альтернативное управление без Telegram-бота:
Если бот недоступен, можете управлять системой через файл `data/buyer_configs.json`:

```json
{
  "buyer_andrei": {
    "enabled": false,  // Отключить покупателя
    "strategies": [
      {
        "min_price": 1,
        "max_price": 100,
        "max_spend": 1000,
        "priority": 1,
        "current_spent": 0  // Сбросить траты
      }
    ]
  }
}
```

После изменения файла покупатель автоматически применит новые настройки.

### Покупатель не работает:
1. Проверьте статус через Telegram-бот
2. Убедитесь, что покупатель включен
3. Проверьте лимиты трат
4. Посмотрите логи покупателя

### Бот не отвечает:
1. Проверьте `MANAGEMENT_BOT_TOKEN` в `app/config.py`
2. Убедитесь, что ваш username добавлен в `ADMIN_USERNAMES`
3. Перезапустите: `python main.py config`

### Конфигурация не применяется:
1. Проверьте синтаксис JSON в `buyer_configs.json`
2. Убедитесь в правильной кодировке (UTF-8)
3. Перезапустите покупателя: `python main.py buyer`
